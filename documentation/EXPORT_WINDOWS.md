# Exporting to Windows

Target: a standalone Windows 10/11 build for the reference machine
(Ryzen 5 5500 / RTX 3050 8 GB), 1080p, ~60 FPS on the Medium preset.

## 1. Install export templates
Editor → **Editor → Manage Export Templates → Download and Install**. The template
version **must match** your editor (e.g. 4.6.3‑stable). Offline: download
`Godot_v4.6.x-stable_export_templates.tpz` from the releases page and **Install from
File**.

## 2. Add a Windows preset
**Project → Export… → Add… → Windows Desktop**.

Recommended preset settings:
- **Binary Format → Embed PCK**: ON for a single `.exe` (or OFF to ship `.exe` + `.pck`).
- **Application → Product Name**: `The Last Ward`; set Company/Version/Icon as desired.
- **Resources → Export Mode**: *Export all resources in the project*.
- Leave **Features** default (the project is configured for **Forward+**; the target
  RTX 3050 supports it).

## 3. Export
- Output path e.g. `build/TheLastWard.exe` → **Export Project** (uncheck *Export With
  Debug* for a release build, which also disables the F2/F3/F4 debug tooling).

### CLI export (no GUI)
```
# Release (debug tooling off):
godot --headless --path . --export-release "Windows Desktop" build/TheLastWard.exe

# Debug (F2 console, F3/F4 overlays enabled):
godot --headless --path . --export-debug   "Windows Desktop" build/TheLastWard.exe
```

## 4. Ship
Distribute `TheLastWard.exe` (and `TheLastWard.pck` if you did **not** embed it).
On first run the game writes saves/settings to
`%APPDATA%\Godot\app_userdata\The Last Ward\`.

## Recommended default graphics for the target GPU
The **Medium** preset (Settings → Graphics) is tuned for ~60 FPS at 1080p on an
RTX 3050: render scale 0.9, medium shadows, low volumetric fog, SSAO on, SSR off,
FXAA. Players can raise to High/Ultra or lower to Low as needed. VSync defaults to
On; a 60 FPS frame cap is set.

## Sample `export_presets.cfg`
`export_presets.cfg` is generated by the editor (and git‑ignored). If you want to
script exports in CI, create it once via the editor, or start from this template
(then let the editor normalise it on first open):

```ini
[preset.0]
name="Windows Desktop"
platform="Windows Desktop"
runnable=true
export_path="build/TheLastWard.exe"
[preset.0.options]
binary_format/embed_pck=true
application/product_name="The Last Ward"
application/file_version="0.1.0.0"
```

## Troubleshooting
- **Black screen / no 3D**: ensure Forward+ templates installed and the GPU supports
  Vulkan. Update GPU drivers.
- **Missing icon**: set the preset's icon to `res://icon.svg` (or a `.ico`).
- **Antivirus flags the exe**: common for unsigned Godot exes; sign the binary for
  distribution.
