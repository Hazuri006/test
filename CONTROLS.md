# Contrôles — DRIFTWAKE

Toutes les touches sont **reconfigurables** dans **Paramètres → Touches** (cliquez sur une
touche puis appuyez sur la nouvelle). Les dispositions **AZERTY (ZQSD)** et **QWERTY
(WASD)** sont gérées via les codes physiques (`KeyW` = position de la touche, donc Z en
AZERTY).

## Déplacement & caméra

| Action                    | Par défaut         |
| ------------------------- | ------------------ |
| Avancer / reculer         | `W` / `S` (Z / S)  |
| Gauche / droite           | `A` / `D` (Q / D)  |
| Regarder                  | Souris             |
| Sprint                    | `Maj` gauche       |
| S'accroupir / **plonger** | `Ctrl` gauche      |
| Sauter / **remonter**     | `Espace`           |

- En nage, la **direction du regard** oriente le déplacement (regardez vers le bas +
  avancez pour plonger). `Ctrl` fait descendre, `Espace` fait remonter.
- L'oxygène descend sous l'eau ; remontez avant qu'il n'atteigne zéro.
- On **remonte automatiquement** sur le radeau ou la plage en s'en approchant (escalade).

## Interaction & outils

| Action                         | Par défaut    |
| ------------------------------ | ------------- |
| Utiliser / frapper / lancer    | Clic gauche   |
| Action secondaire (démolir au marteau) | Clic droit |
| Interagir (E)                  | `E`           |
| Barre rapide (emplacements 1–5) | `1` … `5`     |
| Changer d'emplacement          | Molette       |

Comportement du **clic gauche** selon l'objet équipé :

- **Crochet** : maintenir pour charger, relâcher pour lancer ; rembobinage automatique.
- **Canne à pêche** : lancer la ligne, puis recliquer quand « Ça mord ! ».
- **Hache** : abattre arbres / casser rochers en visant la cible.
- **Lance / lance métallique** : frapper le requin quand il est proche et de face.
- **Marteau** : clic = réparer la pièce visée ; clic droit = démolir.
- **Pièce de construction sélectionnée** : entre en mode construction.

La touche **E** s'adapte au contexte (un texte d'aide s'affiche) : ramasser un débris
proche, cuisiner/récupérer sur le grill, purifier/récupérer de l'eau, ouvrir un coffre
d'île, utiliser la table de recherche.

## Construction (mode build)

| Action            | Par défaut       |
| ----------------- | ---------------- |
| Activer/quitter   | `B`              |
| Poser la pièce    | Clic gauche      |
| Pivoter           | `R`              |
| Annuler           | Clic droit       |

L'aperçu est **vert** si le placement est valide (et abordable), **rouge** sinon. Les
fondations doivent toucher la structure existante.

## Interface

| Action               | Par défaut |
| -------------------- | ---------- |
| Inventaire / craft   | `Tab`      |
| Menu / Pause         | `Échap`    |

Dans l'inventaire : **glisser-déposer** pour ranger, **clic droit** pour diviser une pile,
**clic** sur un objet pour l'utiliser (manger/boire) ou l'équiper, **glisser hors de la
fenêtre** pour jeter. Onglets : Fabrication, Construction, Recherche.

> 💡 Cliquez dans la fenêtre de jeu pour verrouiller le curseur (Pointer Lock). `Échap`
> le libère et ouvre la pause.
